# Khorscape

Mobile-first Astro landing page for Khorscape, a Naperville-area landscaping and outdoor cleanup service.

## Stack

- Astro static site
- Local optimized images through `astro:assets`
- Plain CSS with design tokens
- No client framework and no heavy animation library

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Deployment

Deploy the repository to Vercel, Netlify, Cloudflare Pages, or any static host.

- Build command: `npm run build`
- Output directory: `dist`
- Production domain: `khorscape.com`

## Content notes

The site intentionally avoids fake testimonials, fake stats, ratings, awards, or unsupported licensing/insurance claims. Add those only when they are verified.
